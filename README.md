# OpenCode Web

OpenCode Web is a web-based interface for OpenCode, providing a powerful AI coding experience in your browser.

## Features

- **Web Interface**: Start with `opencode web`.
- **Configurable**: Use `opencode.json` or CLI flags.
- **mDNS Discovery**: Find your server on the local network as `opencode.local`.
- **Terminal Attachment**: Attach a TUI to a running web server with `opencode attach`.
- **Secure**: Password protection via environment variables.

## Installation

```bash
poetry install
```

## Usage

```bash
opencode web --port 4096
```
